    🔗 Kết nối Google Sheet

    Dán đường link Google Apps Script Web App để lưu và đồng bộ kết quả học sinh.

    Hướng dẫn tạo Google Apps Script (bấm để xem)
    1. Mở Google Sheet mới → Tiện ích mở rộng → Apps Script.
    2. Xoá code mẫu, dán đoạn mã bên dưới vào rồi bấm Lưu.
    3. Bấm Triển khai (Deploy) → Triển khai mới (New deployment) → chọn loại Ứng dụng web (Web app).
    4. Mục "Ai có quyền truy cập": chọn Bất kỳ ai (Anyone). Mục "Thực thi với tư cách": chọn Tôi (Me).
    5. Bấm Triển khai, cấp quyền truy cập, rồi copy đường link Web App vừa tạo và dán vào ô phía trên.
    function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var action = e.parameter.action;
  if (action === 'list') {
    var s = ss.getSheetByName('KetQua');
    if (!s || s.getLastRow() < 2) return out_([]);
    var data = s.getDataRange().getValues();
    var headers = data.shift();
    var result = data.map(function(row){
      var obj = {};
      headers.forEach(function(h,i){ obj[h] = row[i]; });
      return obj;
    });
    return out_(result);
  }
  if (action === 'getPassage') {
    var p = ss.getSheetByName('BaiDoc');
    if (!p || p.getLastRow() < 2) return out_({});
    var row = p.getRange(2,1,1,3).getValues()[0];
    return out_({title:row[0], content:row[1], author:row[2]});
  }
  return out_({ok:true});
}

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var data = JSON.parse(e.postData.contents);
  if (data.action === 'setPassage') {
    var p = ss.getSheetByName('BaiDoc') || ss.insertSheet('BaiDoc');
    p.clear();
    p.appendRow(['Tua bai','Noi dung','Tac gia']);
    p.appendRow([data.title, data.content, data.author]);
    return out_({ok:true});
  }
  if (data.action === 'submit') {
    var s = ss.getSheetByName('KetQua') || ss.insertSheet('KetQua');
    if (s.getLastRow() === 0) {
      s.appendRow(['hoTen','lop','tenBai','doChinhXac','soLanDocLai','tuSai','ghiAm','thoiGianNop']);
    }
    s.appendRow([data.hoTen, data.lop, data.tenBai, data.doChinhXac,
                 data.soLanDocLai, (data.tuSai||[]).join(', '), data.ghiAm, data.thoiGianNop]);
    return out_({ok:true});
  }
  return out_({ok:false});
}

function out_(obj){
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

    📝 Giao bài luyện đọc

    Cô dán bài đọc vào đây. Khi bấm lưu, AI sẽ tự tạo 5 câu hỏi đọc hiểu phù hợp với nội dung để học sinh làm ngay trong cùng một link.

    Chọn một bài để xem lại nội dung, chỉnh sửa và lấy lại đúng link cũ.
    Có thể tải MP3, WAV hoặc M4A; audio sẽ được lưu để học sinh ở thiết bị khác vẫn nghe được.
    Học sinh chỉ cần một link này để mở bài đọc và bài tập đọc hiểu tương ứng.
    Cô có thể xem hoặc chỉnh câu hỏi. Sau khi chỉnh, bấm “Tạo link” ở ô phía trên để cập nhật cùng một link cho học sinh.
